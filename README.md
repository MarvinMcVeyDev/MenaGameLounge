# Mena Game Lounge — Business Website Project

## Overview

A business website concept developed for Mena Game Lounge to demonstrate web development skills and explore how a dedicated website could present the business, its services, and contact information.

The website is published as a demonstration project and is not currently used as the business’s official public website.

## Project Goals

Create a professional online presence for a local business.
Organize business information into an accessible website.
Implement responsive layouts and intuitive navigation.
Apply practical web development skills to a real-world business scenario.

## Features

Responsive website layout
Business information and service presentation
Navigation between website sections or pages
Contact information and calls to action

## Technologies

HTML5
CSS3
JavaScript
BootStrap

## Project Status

Published demonstration project. The website is available to view online but has not been adopted as the business’s official website.
